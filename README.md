## Fitur

- Hero hidup: video + foto Ken Burns, kabut berlapis, partikel canvas, parallax mouse & scroll
- Reel sinematik drag-inertia (Profil & Pendidikan): snap tengah, progress bar, prev/next, keyboard
- Tanda tangan animasi: huruf R + 5 gelombang + ekor, digambar otomatis saat scroll
- Filter karya (Web / Desain / Tugas), skill bar animasi, counter statistik
- Form kontak via WhatsApp deep link (berfungsi offline maupun online)
- Progress bar scroll, navbar auto-hide, reveal stagger, mode hemat gerak (`prefers-reduced-motion`)

## Struktur

```
├── index.html   # struktur + konten
├── style.css    # palet earthy (#6E3511 #91AC67 #597928 #FCECD8) + seluruh styling
├── script.js    # semua interaksi (native, tanpa library)
├── PRD.md       # dokumen perancangan
└── assets/      # foto lokal
```

## Cara menjalankan

Tanpa build, tanpa server — cukup buka `index.html` di browser. Atau serve lokal:

```bash
npx serve .
```
